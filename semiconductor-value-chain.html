Product Taxonomy

Commercial/device classification with drill-down from product class → product family → generation/form factor → representative company/product. Manufacturing nodes are shown as implementation links inside the product detail rather than duplicated as product children.

Axis = Product / Device class

Click any product to open its sub-products, representative company logos/product families, and common process-implementation links. The tree stays typed: process node ≠ product subtype.

Root taxonomy

Logic, Memory, Analog, Discrete, Optoelectronics, Sensors & Actuators are anchored to SIA/WSTS market classification.

Implementation link

Logic products can display N7/N5/N3/N2, Samsung GAA or Intel 18A as implementation links without misclassifying process nodes as products.

Module rule

DIMM, SOCAMM2 and CXL memory are downstream form factors/system products, not new DRAM cell technologies.

Evidence rule

Company/product mapping is added only after direct product/capability evidence; blank coverage is preferable to invented completeness.

IC Design / IP Capability Ontology

Engineering capability classification: what must be architected, implemented, verified or integrated inside an IC or multi-die system? Protocol standards, PHYs, SerDes circuits and design-service disciplines are intentionally separated.

Axis = Design function / IP block

This page answers whether a company designs a controller, PHY, SerDes, RTL, physical implementation, verification IP or multi-die integration — not merely whether it “supports CXL/UCIe/HBM.”

Packaging Technology Map · 封裝技術地圖

Classifies how finished dies are electrically, mechanically and thermally integrated: from wire-bond and flip-chip packages to fan-out, 2.5D interposers/bridges, 3D hybrid bonding, panel/wafer-scale integration and co-packaged optics.

Axis = Package architecture / die integration

Start with package architecture, then drill into vendor platforms such as CoWoS, InFO, EMIB, Foveros, Samsung Cube and ASE VIPack. Product/process-node taxonomy stays on the Products page.

Classification rule: package form (QFN/FCBGA), integration architecture (fan-out/2.5D/3D), and vendor platform (CoWoS/EMIB/InFO) are separate levels. Emerging names such as CoPoS are marked Research Queue until public technical documentation matures.

Application Lens

End-use segmentation over the same semiconductor products. Application is not a parent of process technology: a 28nm BCD device can be automotive, industrial or consumer depending on product and qualification.

Axis = End market / workload
